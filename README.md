# File-System-BFS-DFS


 File System Representation and Search Using BFS and DFS in C Visibility.
## Objectives
- Represent files and directories as graph nodes.
- Implement Breadth-First Search (BFS).
- Implement Depth-First Search (DFS).
- Search for a specified file using both algorithms.

## Technologies Used
- Programming Language: C
- Data Structure: Graph
- Representation: Adjacency Matrix

## Files Included
- filesystem.c - C source code
- input.txt - Sample input
- output.txt - Sample output

## Conclusion
This project demonstrates how BFS and DFS algorithms can be used to search files in a graph-based file system.
